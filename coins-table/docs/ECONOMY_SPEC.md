# ECONOMY_SPEC — формулы и баланс

Единственный источник чисел. Код читает значения из `src/data/*`, тесты проверяют формулы из этого документа. Все числа стартовые и подлежат тюнингу (меняй здесь, потом в данных и тестах).

## 1. Общие правила
- Валюта: **Gold** (BigInt-безопасная реализация, см. `ARCHITECTURE.md`). Нет платной валюты.
- Стоимость уровня: `cost(level) = floor(baseCost * growth^level)`, где `level` — текущий уровень (покупка уровня `level → level+1`).
- Покупка x10 и Max: сумма стоимостей последовательных уровней. Max = максимум, на который хватает Gold, с учётом `maxLevel`.
- Все случайные события используют инъектируемый `Rng` (seed в тестах).
- Округления: доход за монету округляется вниз до целого, минимум 1.

## 2. Доход за монету
```
coinBase   = 1 + coinValueLevel
multiplier = tableMultiplier * goldenHourMultiplier * frenzyMultiplier
coinGold   = max(1, floor(coinBase * multiplier * specialCoinFactor))
```
`specialCoinFactor`: 1 по умолчанию; ×5 для Lucky Coin; ×10 для Diamond Coin. Если выпали оба, берётся максимум (не произведение).

## 3. Столы (`src/data/tables.ts`)
| id | Название | Цена открытия | Множитель |
|---|---|---|---|
| wooden | Wooden Table | 0 | ×1 |
| marble | Marble Table | 5 000 | ×3 |
| royal | Royal Table | 250 000 | ×10 |
- Открытие покупается за Gold один раз и сохраняется. Нельзя купить закрытый стол без средств.
- Активен один стол; множитель применяется к активному.
- Upgrades глобальные (общие для всех столов). Статистика (подбросы, заработано) ведётся по столам.

## 4. Upgrades за Gold (`src/data/upgrades.ts`)
| id | baseCost | growth | maxLevel | Эффект |
|---|---|---|---|---|
| coinValue | 10 | 1.15 | ∞ | `+1` к `coinBase` за уровень |
| autoTosser | 50 | 1.18 | 100 | `0.5 * level` авто-подбросов/с |
| tossSpeed | 100 | 1.25 | 20 | множитель скорости авто `1 + 0.1 * level` |
| multiToss | 250 | 1.30 | 10 | шанс `0.05 * level` на доп. монету за подброс (макс. 0.5) |
| luckyCoin | 500 | 1.35 | 15 | шанс `0.02 * level` монеты ×5 (макс. 0.3) |
| offlineVault | 200 | 1.40 | 10 | лимит офлайн `4ч + 0.5ч * level`, эффективность `0.5 + 0.05 * level` |

Авто-подбросы/с (итог) = `0.5 * autoTosserLevel * (1 + 0.1 * tossSpeedLevel)`.
Тап: 1 монета (+ `magnetTouch` бонус, + multiToss шанс). Зажатие: авто-тап не чаще 8 тапов/с.

## 5. Ad Boosts за rewarded (`src/data/adBoosts.ts`)
Каждый уровень покупается просмотром одной rewarded-рекламы. Награда выдаётся только после подтверждения Bridge.

| id | Уровни | Эффект |
|---|---|---|
| goldenHour | 3 | множитель дохода ×2 / ×3 / ×4 (не накапливается, берётся значение текущего уровня) |
| diamondCoins | 3 | шанс монеты ×10: 5% / 10% / 15% |
| magnetTouch | 2 | `+1` / `+2` дополнительные монеты за тап |
| timeWarp | повторяемый | мгновенно начисляет доход за 10 минут при текущем авто-доходе, кулдаун 5 мин |
| frenzy | повторяемый | ×5 к доходу на 60 с по кнопке, кулдаун 5 мин (после просмотра) |

Правила:
- Для уровня N требуется уровень N−1 (последовательно).
- Если `isRewardedSupported === false`: вкладка скрыта, бонусы не продаются.
- Временные эффекты (frenzy) и кулдауны считаются по `Clock`, сохраняются как метки времени, корректно переживают перезагрузку и офлайн.
- Отмена, ошибка, закрытие рекламы без `rewarded`: награды нет, состояние не меняется.

## 6. Офлайн-доход
```
elapsed  = min(now - lastSeen, offlineCapSeconds)
offline  = floor(autoIncomePerSecond * elapsed * offlineEfficiency)
```
- `lastSeen` пишется в Storage при сохранении и при уходе в фон.
- Минимальный порог показа окна: 30 с отсутствия и `offline ≥ 1`.
- Collect x2: опциональная rewarded-кнопка удваивает сумму. Без рекламы игрок получает базовую сумму.
- Часы не доверяем: если `now < lastSeen` (откат часов), офлайн = 0.
- Временные эффекты во время офлайна не действуют (frenzy не продлевается), кулдауны тикают.

## 7. Форматирование чисел
- `< 1 000`: целое. Далее суффиксы `K, M, B, T, Qa, Qi, Sx, Sp, Oc, No, Dc`, затем научная запись `1.23e45`.
- Максимум 3 значащие цифры у суффикса (`1.23M`). Округление вниз.
- Отрицательных значений быть не может (инвариант).

## 8. Инварианты (проверяются property-тестами)
1. Gold никогда не отрицательный.
2. Покупка уменьшает Gold ровно на сумму стоимости.
3. Уровень не превышает `maxLevel`.
4. Монотонность: больше уровней → доход не уменьшается.
5. Сохранить → загрузить → состояние идентично.
6. Один и тот же seed и последовательность действий дают один и тот же результат.

## 9. Экономические ориентиры (для тюнинга, не требование)
- Первая покупка coinValue за ≤ 10 с игры.
- Marble Table достижим за ≈ 15–25 минут активной игры.
- Royal Table достижим за ≈ 3–6 часов смешанной игры (активно и идл).
- Задай симулятор баланса в `scripts/sim-economy.ts` (см. `TEST_PLAN.md`), чтобы проверять ориентиры без ручной игры.
