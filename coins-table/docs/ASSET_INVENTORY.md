# ASSET_INVENTORY

Все ассеты лежат внутри сборки, имена только латиницей, лицензии записаны в `CREDITS.md`. Размерный бюджет всей игры: цель ≤ 10 МБ (фактический размер сборки `game.zip` 0.40 МБ).

## Правила
- Только CC0 или лицензии, разрешающие коммерческое использование и распространение; указывать источник, автора, лицензию, дату.
- Звук: готовые сжатые звуки (ogg), лицензия Kenney CC0.
- Геометрия: оптимизированные Three.js геометрии с инстансингом монет (InstancedMesh) для минимальных draw calls (7 draw calls, 408 tris).
- Шрифты: подмножество latin+cyrillic, woff2, лицензия OFL (Nunito, Philosopher).
