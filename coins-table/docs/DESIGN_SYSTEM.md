# DESIGN_SYSTEM

Визуальный язык: «тёплая роскошь без казино». Золото, дерево, мрамор, бархат, мягкий свет. Никакой игорной символики (карты, кости, фишки казино, неон-джекпот).

## Принципы
1. Читаемость важнее декора: числа Gold всегда контрастны.
2. Один акцент (золото) + нейтральная тёмная база. Второй акцент (синий) только для rewarded.
3. Тактильность: отклик на каждое действие (анимация + звук).
4. Свой UI: нет эмодзи вместо иконок, нет «дефолтного» шаблона; все иконки SVG, нарисованы под игру.
5. Всё локализуемо: никакого текста в картинках.

## Типографика
- Заголовки и числа: геометрический гротеск с цифрами одинаковой ширины (tabular), например Rubik/Sora (локальный файл, лицензия OFL).
- Основной: тот же семейство с меньшим весом. Файлы шрифтов лежат в сборке, без CDN. Подмножество символов latin + cyrillic.
- Шкала: 12 / 14 / 16 / 20 / 28 / 40 px; числа Gold 28–40 px.

## Компоненты
- **Button primary:** золотой градиент, тёмный текст, радиус 12, нажатие: scale 0.97.
- **Button rewarded:** синий градиент с иконкой «play-ad», подпись «Watch ad». Всегда отличим от золотых.
- **Button secondary:** тёмная заливка, золотая обводка 1 px.
- **Card (upgrade):** тёмная панель, иконка слева, название, уровень (бейдж), эффект, цена справа.
- **Tab:** подчёркивание золотом у активной; Ad Boosts-вкладка с синим индикатором.
- **Badge:** уровень, Locked, Active.
- **Toast:** короткие сообщения 2 с.
- **Modal:** тёмный фон с затемнением, радиус 16, крестик в правом верхнем углу.
- **Progress / Cooldown ring:** золотое кольцо вокруг иконки.
- **Segmented control:** x1 / x10 / Max.
- **Floating text `+N`:** золото, чёрная тень, всплывает 600 мс.

## Иконки (набор SVG, 24 px сетка)
coin, coin-value, auto-tosser, speed, multi, lucky-star, vault, ad-play, hourglass (time warp), flame (frenzy), magnet, diamond, table, lock, mute, sound, settings, globe, close, chevron, check. Единый стиль: заливка + 2 px контур, скругления.

## 3D стиль
- Материалы PBR; лёгкий env map (HDRI не больше 256 КБ, сжатый).
- Освещение: ключевой направленный + мягкий заполняющий + тёплый акцент. Тени мягкие (PCFSoft), ограниченное разрешение.
- Монета: радиус/толщина как у реальной (≈ 1:0.08), ободок, рельеф (normal map 128–256 px), золото `metalness 1, roughness 0.25`.
- Частицы: блёстки при крупных монетах (ограничено: ≤ 60 частиц).
- Камера: сверху под углом ~55°, лёгкий параллакс от указателя (≤ 2°).
- Каждый стол: своя палитра (дерево/сукно, мрамор/синее, тёмное дерево/бордо/золото).

## Анимация
- Длительности: микро 100–150 мс, обычные 200–300 мс, переходы стола 500–600 мс.
- Easing: `cubic-bezier(.2,.8,.2,1)`.
- `prefers-reduced-motion`: отключить параллакс, блёстки, уменьшить тряску.

## Доступность
- Контраст текста ≥ 4.5:1.
- Цели нажатия ≥ 44 px.
- Не полагаться только на цвет (иконка + текст).
- ARIA-метки у кнопок, управляемых с клавиатуры (Tab/Enter/Space; **без Esc**).

## Запреты
Эмодзи вместо иконок, стоковые «шаблонные» панели, чужие бренды и шрифты без лицензии, неон и игорная эстетика, текст на картинках.
