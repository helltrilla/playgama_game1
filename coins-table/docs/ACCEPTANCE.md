# ACCEPTANCE — критерии приёмки

Формат: `AC-<область>-<номер>`. Каждый критерий проверяем автотестом (unit `U`, e2e `E`, ручной `M`). Трассировка AC → тест ведётся в `TEST_PLAN.md`. Критерии Playgama (`AC-PG-*`) дублируют `PLAYGAMA_COMPLIANCE.md`.

## Игровой цикл (GAME)
- **AC-GAME-1** (U) Тап добавляет одну монету; Gold растёт на `coinGold` по `ECONOMY_SPEC §2`.
- **AC-GAME-2** (U) Зажатие даёт авто-тапы не чаще 8/с.
- **AC-GAME-3** (U) Авто-подброс считается по формуле `ECONOMY_SPEC §4` независимо от FPS (тест с разными `dt`).
- **AC-GAME-4** (U) Multi Toss и Lucky Coin срабатывают с заданной вероятностью (статистика на фиксированном seed).
- **AC-GAME-5** (E) Анимация монеты: взлёт, вращение, 1–2 отскока, исчезновение; число активных монет ограничено пулом.
- **AC-GAME-6** (E) На месте падения появляется `+N`, звук воспроизводится (если звук включён).

## Экономика (ECO)
- **AC-ECO-1** (U) `cost(level)` совпадает с формулой для всех апгрейдов.
- **AC-ECO-2** (U) Покупка недоступна без средств и на `maxLevel`; Gold не уходит в минус.
- **AC-ECO-3** (U) Режимы x1/x10/Max считают сумму и количество уровней верно.
- **AC-ECO-4** (U) Множители стола, Golden Hour и Frenzy применяются по `§2`.
- **AC-ECO-5** (U) Форматирование чисел по `§7` (граничные значения 999, 1000, 1e6, 1e33, 1e45).
- **AC-ECO-6** (U) Инварианты `§8` проходят property-тесты.

## Столы (TBL)
- **AC-TBL-1** (U) Wooden открыт с начала, Marble и Royal закрыты.
- **AC-TBL-2** (U) Открытие стола списывает цену один раз и сохраняется.
- **AC-TBL-3** (E) Переключение стола: плавная камера, материалы и свет меняются, состояние монет не ломается.
- **AC-TBL-4** (U) Добавление нового стола в `tables.ts` не требует правок в `core` (тест на фиктивном столе).

## Ad Boosts и офлайн (ADS, OFF)
- **AC-ADS-1** (U) Награда rewarded выдаётся только после события `rewarded`.
- **AC-ADS-2** (U) Отмена, ошибка, закрытие без награды не меняют состояние.
- **AC-ADS-3** (U) Уровни ad-веток покупаются последовательно; эффекты по `§5`.
- **AC-ADS-4** (U) Frenzy и кулдауны живут по `Clock` и переживают сохранение и загрузку.
- **AC-ADS-5** (E) При `isRewardedSupported=false` вкладка Ad Boosts и все rewarded-кнопки скрыты.
- **AC-OFF-1** (U) Офлайн-доход по `§6` (лимит, эффективность, порог, откат часов).
- **AC-OFF-2** (E) Окно Welcome back показывает сумму; Collect начисляет базу; Collect x2 только после rewarded.

## Сохранения (SAVE)
- **AC-SAVE-1** (U) Состояние сериализуется и восстанавливается без потерь (round-trip).
- **AC-SAVE-2** (U) При старте один вызов `storage.get([...])`, при записи один вызов `storage.set` со всеми изменёнными ключами.
- **AC-SAVE-3** (U) Запись не чаще одного раза в 5 с (debounce) и принудительно при уходе в фон.
- **AC-SAVE-4** (U) Миграция старой версии сейва поднимает его до текущей без потерь; повреждённые данные дают безопасный дефолт.
- **AC-SAVE-5** (E) После перезагрузки страницы прогресс восстановлен.

## Платформа Playgama (PG)
- **AC-PG-1** (E) Bridge-скрипт первый в `<head>`, без `async`; инициализация завершается до старта игры.
- **AC-PG-2** (E) `playgama-bridge-config.json` лежит рядом с `index.html` и валиден.
- **AC-PG-3** (U) Язык из `platform.language`, fallback `en`; все ключи есть в `en`.
- **AC-PG-4** (E) В коде и рантайме нет `localStorage`, `sessionStorage`, IndexedDB, cookies.
- **AC-PG-5** (U/E) При паузе и `isAudioEnabled=false` игра стоит, звук выключен; после возврата продолжается.
- **AC-PG-6** (E) `game_ready` отправлен ровно один раз после первого играбельного кадра.
- **AC-PG-7** (U) Interstitial вызывается на естественных паузах; своих таймеров нет.
- **AC-PG-8** (E) Неподдерживаемое скрыто (rewarded, магазин, лидерборды, внешние ссылки, вход).
- **AC-PG-9** (E) Нет сетевых запросов, кроме Bridge и ассетов игры.
- **AC-PG-10** (U) Аналитика только через `bridge.analytics.send`.
- **AC-PG-11** (U) Если Bridge не инициализировался, игра запускается в mock-режиме без падений.

## UX и адаптивность (UX)
- **AC-UX-1** (E) Нет скролла страницы; панель прокручивается внутри.
- **AC-UX-2** (E) Матрица размеров из `TEST_PLAN §4`: без перекрытий и обрезки, текст читаем.
- **AC-UX-3** (E) Квадрат 1:1 заполнен без пустых полос; на десктопе поле не шире 2:1.
- **AC-UX-4** (E) Долгое нажатие не выделяет текст и не открывает контекстное меню.
- **AC-UX-5** (E) У каждого попапа есть кнопка закрытия; Esc не используется.
- **AC-UX-6** (E) Поворот, ресайз, сворачивание, реклама не сбрасывают прогресс и не ломают управление.
- **AC-UX-7** (M) Mute работает мгновенно и сохраняется.

## Производительность (PERF)
- **AC-PERF-1** (E) Draw calls ≤ 60, треугольники ≤ 150k.
- **AC-PERF-2** (M) ≥ 55 FPS на целевом среднем телефоне при 50 активных монетах.
- **AC-PERF-3** (E) Нет роста памяти в 10-минутном прогоне.
- **AC-PERF-4** (E) Потеря и восстановление WebGL-контекста не ломают игру.
- **AC-PERF-5** (E) Размер `game.zip` ≤ 10 МБ (цель), жёсткий лимит 300 МБ.
- **AC-PERF-6** (E) Рендер-цикл остановлен при скрытой вкладке и на паузе.

## Локализация и контент (LOC)
- **AC-LOC-1** (U) Ключи `en` и `ru` совпадают.
- **AC-LOC-2** (U) Запрещённые слова (`casino`, `bet`, `jackpot`, `slot` и др.) не встречаются в строках.
- **AC-LOC-3** (E) Ручное переключение языка работает; названия языков на родных языках.
