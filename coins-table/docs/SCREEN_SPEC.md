# SCREEN_SPEC — экраны и поведение

Раскладка адаптивная: canvas занимает всю область, UI — HTML поверх. Нет скролла страницы (`100dvh`, `overflow:hidden`). Учитывать safe-area (`env(safe-area-inset-*)`).

## 1. Loading
- Фон тёмный, логотип, прогресс-бар, подсказка. Без внешних ресурсов.
- Прогресс отражает реальную загрузку ассетов. После готовности первого кадра → экран скрывается → `game_ready`.
- При сбое загрузки: сообщение «Something went wrong» и кнопка Retry (без технических текстов).

## 2. Main (игровой экран)
Зоны:
- **Верхняя полоса:** Gold (крупно, форматированный), доход/с, кнопки Mute и Settings, переключатель столов.
- **Центр:** 3D-стол, тап подбрасывает монету из точки касания; `+N` всплывают рядом.
- **Справа (landscape/desktop):** панель прокачки. **Портрет:** сворачиваемая нижняя шторка (высота ≤ 45%), по умолчанию свернута, кнопка-«ручка».
- **Подсказка в первые секунды:** «Tap the table» (скрывается после первого тапа).

Поведение:
- Тап и зажатие по столу, не по UI. Тап по панели не подбрасывает монету.
- Пауза (реклама, фон): затемнение и иконка паузы только если пауза долгая (> 1 с).

## 3. Панель прокачки
Вкладки: **Upgrades** | **Ad Boosts** (вторая скрыта без поддержки rewarded).

**Upgrades:** список карточек: иконка, название, уровень, эффект «было → станет», цена. Кнопка Buy; режим x1 / x10 / Max (сегмент-переключатель). Недоступное затемнено, не скрыто. Скролл только внутри панели.

**Ad Boosts:** карточки с отметкой «Watch ad». Состояния: доступно, куплено (уровень), заблокировано (требуется предыдущий уровень), кулдаун (таймер). Для Frenzy: кнопка Activate и обратный отсчёт. Нижняя строка: «Ads are optional» (локализуется). Блокировка кнопки на время показа.

## 4. Выбор стола
Стрелки или мини-карусель вверху. Карточка стола: название, множитель, статус (Active / Locked + цена / Owned). Закрытый стол: кнопка Unlock (если хватает Gold). Смена: плавный переход камеры и материалов (≤ 600 мс).

## 5. Welcome back (офлайн)
Окно по центру: «Welcome back!», время отсутствия, сумма Gold. Кнопки: **Collect** (основная) и **Collect x2 (watch ad)** (вторичная, скрыта без rewarded). Крестик закрытия (эквивалент Collect). После закрытия может идти interstitial (см. `PLAYGAMA_INTEGRATION`).

## 6. Settings
Звук (Mute), музыка/эффекты (опционально), язык (список на родных языках, иконка глобуса), сброс прогресса (двойное подтверждение, отдельным окном), версия игры. Крестик закрытия. Без внешних ссылок.

## 7. Подтверждающие и ошибочные состояния
- Нехватка Gold: кнопка недоступна, лёгкое «встряхивание» цены.
- Ошибка или отмена rewarded: короткий тост «Ad unavailable, try again later», игра продолжается.
- Любое окно имеет крестик, закрывается и по тапу вне окна (кроме подтверждения сброса).

## 8. Анимации и отклик
Нажатия: ≤ 100 мс отклик; покупка: подсветка карточки и звук; число Gold плавно «тикает». Уважать `prefers-reduced-motion`.

## 9. Адаптивные правила
| Условие | Поведение |
|---|---|
| Landscape ≥ 900 px | панель справа, ширина 320–380 px |
| Portrait / узкий | нижняя шторка |
| Очень широкий (> 2:1) | поля по бокам, игровое поле ≤ 2:1 |
| Квадрат 1:1 | поле заполнено, шторка свернута, без пустых полос |
| Низкая высота (< 420 px) | компактный режим: уменьшенные отступы, одна колонка |

Минимальный размер шрифта 12 px (интерактивные элементы ≥ 14 px; цели нажатия ≥ 44 px).
