## Финальные проверки после сборки
1. Запуск `npm run verify` — сборка `game.zip` 0.40 МБ, все 15 compliance проверок зелёные.
2. Запуск `npm run test:e2e` — 9/9 сквозных и визуальных тестов пройдены.
3. Проверено: `game_ready` вызывается ровно один раз после рендера, сохранение через bridge.storage восстанавливается, реклама не блокирует интерфейс.
